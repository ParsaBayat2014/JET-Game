# Security policy

## Supported version

The `main` branch is the supported development line for this repository. Older APKs and releases may not receive fixes.

## Reporting a vulnerability

Please do not open a public issue for an exploitable vulnerability. Use GitHub's private vulnerability reporting feature for this repository, if available. If it is unavailable, open a minimal issue asking for a private contact channel without including exploit details.

Include the affected version or commit, impact, reproduction steps, and any suggested mitigation. Remove passwords, signing keys, purchase receipts, personal data and device logs from reports.

The maintainer will acknowledge a valid report, assess severity, prepare and test a fix, and document the resolution in a release note when disclosure is safe.

## Scope

Relevant areas include local save integrity, receipt handling, network/local multiplayer boundaries, exported Android components, build configuration and dependency risks. This version does not claim server-authoritative purchases or online matchmaking.
