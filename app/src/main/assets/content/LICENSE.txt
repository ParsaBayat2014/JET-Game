Music is stereo 44.1 kHz 16-bit PCM. Each track is an original repeating
arrangement of chords, melodic phrases, bass, soft percussion, and stereo echo.
World illustrations are 1080 x 1920 JPEG optimized for a readable flight lane.
This is usable game content, with no padding files added to inflate the package.
