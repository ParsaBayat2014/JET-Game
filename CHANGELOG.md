# Changelog

## 2.0.0 — build 206

- Native Java Android arcade game with GLES2 and Canvas rendering.
- 48 campaign stages and local multiplayer modes.
- Offline soundtrack generation with SHA-256 verification for 12 tracks.
- Unit tests, debug lint configuration and reproducible build instructions.
- Known limitations documented: real purchases and two-physical-phone multiplayer still require device/service validation.

This changelog records verified repository history. It does not claim store approval, revenue, downloads or active users.
