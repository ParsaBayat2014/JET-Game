# Support

## Before asking for help

1. Check [BUILD.md](BUILD.md) and confirm the JDK, Android SDK and Python versions.
2. Search existing issues for the same symptom.
3. Reproduce the problem on the latest `main` commit when possible.
4. Remove credentials, signing keys, purchase receipts and personal logs.

## Where to ask

- Use a bug report for a reproducible defect.
- Use a feature request for a focused user need.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

JET is maintained by a small project team. Support is best-effort and does not promise store publication, billing activation or device certification.
