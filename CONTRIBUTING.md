# Contributing to JET

Thanks for helping improve JET.

1. Read `BUILD.md` and set up the Android build environment.
2. Open an issue before starting a large change.
3. Keep pull requests focused and explain the user-visible impact.
4. Add or update tests for changes to game logic.
5. Do not include credentials, signing keys, private logs or personal data.
6. Include the commands or device checks used to test the change.

Contributions are provided under the repository's GNU GPL v3 license.
